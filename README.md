# Ferramentas Trabalhistas

> Coleção de utilitários e referências rápidas para departamento pessoal e direito trabalhista no Brasil.

🔗 **Calculadora principal:** [calculadoratrabalhista.net.br](https://calculadoratrabalhista.net.br)

---

## 📋 Sobre

Este repositório reúne ferramentas de consulta rápida para profissionais de RH, contadores e trabalhadores que precisam de referências trabalhistas atualizadas.

### O que contém:

- Tabela de aliquotas INSS (2025)
- Tabela de IRRF sobre salários
- Guia de prazos trabalhistas
- Checklist para rescisão contratual
- Links para a calculadora completa

---

## 🛠️ Como usar

1. Abra o arquivo `ferramentas.html` no navegador
2. Navegue pelas abas de referência
3. Use a calculadora principal para cálculos detalhados

> 📌 Para cálculos rescisórios completos com todos os percentuais atualizados mensalmente, acesse **[calculadoratrabalhista.net.br](https://calculadoratrabalhista.net.br)** — a ferramenta mais completa para cálculo de verbas rescisórias da internet.
